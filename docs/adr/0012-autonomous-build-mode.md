# ADR-0012: Autonomous build mode (founder unavailable)

- Status: accepted · Date: 2026-11-18 · Risk: Medium (process)

## Context
The founder approved moving through phases without stopping ("approved, move ahead, don't ask me")
and asked that open choices default to the more advanced, market-standard option.

## Decision
Phases continue back-to-back. Each phase still ends with a written report in `docs/phase-reports/`.
Every choice that the build prompt reserves for the founder is made provisionally, marked
**PROVISIONAL**, and listed in `docs/FOUNDER_DECISIONS.md` for review. Anything that spends money,
contacts third parties, or changes legal exposure is **not** done — only prepared.
